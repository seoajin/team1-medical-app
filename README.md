# 🏥 서해보건ON

학생들이 보건실을 이용할 때 사람이 많거나 선생님이 안 계셔서 생기는 불편함을 줄이는 웹 앱이에요.
휴대폰 브라우저에서 바로 쓰고, "홈 화면에 추가"하면 앱처럼 쓸 수 있어요.

## 할 수 있는 것

**🎒 학생용**
- 📡 실시간 현황: 선생님이 계신지, 오늘 예약자 수, 빈 침대, 예상 대기 시간
- 📅 보건실 예약: 학번·이름을 적고 쉬는 시간과 증상을 골라 예약 (내 순서 확인, 취소 가능)
- 🛏️ 침대 사용 요청: 증상을 꼭 적어야 요청 가능, 허용되면 침대 번호와 남은 시간 표시
- ⏰ 침대 사용 1시간이 지나면 "교실로 돌아가요" 알림
- 🎬 자가 응급처치 영상 4개 (코피, 긁힌 상처, 발목 삠, 화상): 단계를 누르면 그 장면으로 이동
- 📱 전자 보건확인증: 선생님이 "진료 완료"를 누르면 **예약 시간 ~ 진료 완료 시간**이 적힌 확인증이 발급돼요
- ▶ 맨 위 사용법 영상

**🧑‍⚕️ 선생님용** (암호 필요, 처음 암호 `1234`)
- 침대 사용 요청 허용·거부 (거부 이유 선택), 침대 비우기
- 침대 1시간이 지나면 "침대 정리 요청" 알림
- 오늘 예약 명단(학번·이름·증상) → 처치 내용 고르고 "🩺 진료 완료"
- 내 상태(자리에 있음 / 진료 중 / 잠시 자리 비움 / 오늘 안 계세요)와 학생에게 남길 메모
- 선생님 모드 암호 바꾸기

## 1단계. 깃허브에 올려서 웹사이트로 만들기 (GitHub Pages)

1. [github.com](https://github.com) 에 로그인 → 오른쪽 위 **+** → **New repository**
2. 저장소 이름을 정해요. **띄어쓰기 없이** 영어로 (예: `seohae-health-on`) → **Public** → **Create repository**
3. **uploading an existing file** 을 눌러 이 폴더의 파일과 폴더(`icons`, `videos` 포함)를 **전부** 끌어다 놓고 → **Commit changes**
4. 저장소의 **Settings → Pages** → Source: **Deploy from a branch** → Branch: **main**, 폴더: **/(root)** → **Save**
5. 1~2분 뒤 `https://내아이디.github.io/seohae-health-on/` 주소로 열려요. 이 주소를 학생들에게 알려 주세요.

> 여기까지만 하면 **각 휴대폰 안에만** 저장돼요. 학생 휴대폰과 선생님 기기를 연결하려면 2단계를 해 주세요.

## 2단계. Firebase 연결하기 (학생 휴대폰 ↔ 선생님 기기 실시간 연결)

Firebase는 구글이 만든 무료 온라인 데이터베이스예요. 팀원 한 명의 구글 계정으로 만들면 돼요.

1. [console.firebase.google.com](https://console.firebase.google.com) → **프로젝트 추가** → 이름 입력 (구글 애널리틱스는 꺼도 돼요)
2. 프로젝트 첫 화면에서 **웹 앱 추가(`</>` 아이콘)** → 앱 이름 입력 → 나오는 `firebaseConfig = { ... }` 의 `{ ... }` 부분을 복사
3. `config.js` 를 열어 `firebase: null,` 을 지우고 복사한 내용을 이렇게 붙여 넣어요:
   ```js
   firebase: {
     apiKey: "...",
     authDomain: "....firebaseapp.com",
     projectId: "...",
     storageBucket: "...",
     messagingSenderId: "...",
     appId: "..."
   },
   ```
   (이 값은 공개돼도 괜찮아요. 누가 무엇을 할 수 있는지는 4번의 보안 규칙이 지켜 줘요.)
4. **Authentication** → **시작하기** → 로그인 방법에서 **익명** 과 **이메일/비밀번호** 를 **사용 설정**
5. **Authentication → Users → 사용자 추가**
   - 이메일: `config.js` 의 `teacherEmail` 과 똑같이 (기본값 `teacher@seohae-on.app`, 실제 메일이 아니어도 돼요)
   - 비밀번호: **`seohaeON-1234`** (앱에서 누르는 암호 `1234` 앞에 `seohaeON-` 이 붙은 거예요)
6. **Firestore Database** → **데이터베이스 만들기** → 위치 **asia-northeast3 (서울)** → **프로덕션 모드**로 시작
7. Firestore의 **규칙(Rules)** 탭 → `firestore.rules` 파일 내용을 통째로 붙여 넣고 **게시**
   - 이메일을 바꿨다면 규칙 안의 `teacher@seohae-on.app` 도 똑같이 바꿔 주세요.
8. **Authentication → 설정 → 승인된 도메인** 에 `내아이디.github.io` 추가
9. 고친 `config.js` 를 깃허브에 다시 올리면 끝! 앱 맨 아래에 **"🟢 온라인 연결됨"** 이 보이면 성공이에요.

## 선생님 암호

- 처음 암호는 `1234` 예요. 선생님용 화면 아래 **암호 바꾸기**에서 숫자 4~8자리로 바꿀 수 있어요.
- 암호를 잊으면: Firebase 콘솔 → Authentication → Users → 선생님 계정 → 비밀번호 재설정에서 `seohaeON-새암호` 로 바꾸면 돼요.
- 5번 틀리면 30초 동안 입력할 수 없어요. 새로고침하거나 "잠그고 돌아가기"를 누르면 다시 잠겨요.

## 꼭 알아 두세요

- **개인정보**: 학번·이름·증상은 민감한 정보예요. 실제로 쓰기 전에 **보건 선생님과 학교의 허락**을 받아 주세요.
  다른 학생에게는 순서만 보이고 이름·증상은 보이지 않게 막아 두었어요.
- 학생은 로그인 없이 쓰기 때문에, 다른 사람의 학번을 적는 걸 완전히 막지는 못해요.
  학교 계정 로그인을 붙이면 더 안전해져요.
- 응급처치 영상은 일반적인 기본 안내예요. **보건 선생님께 내용을 한 번 확인받아** 주세요.
- Firebase 무료 요금제(Spark)로 한 학교가 쓰기에는 충분해요.

## 파일 설명

| 파일 | 하는 일 |
|---|---|
| `index.html` | 화면 (학생용·선생님용이 한 파일에) |
| `style.css` | 디자인 (휴대폰 화면 포함) |
| `config.js` | **팀이 고치는 설정** (Firebase 값, 선생님 이메일, 침대 수, 침대 사용 시간) |
| `db.js` | 데이터 저장 (Firebase 또는 이 기기) |
| `shared.js` | 함께 쓰는 도우미 (선생님 상태, 예약 시간표, 알림 창) |
| `script.js` | 학생용 기능 |
| `teacher.js` | 선생님용 기능과 암호 |
| `videos.js` | 응급처치 영상 목록과 플레이어, 사용법 영상 |
| `videos/` | 영상 파일 (mp4)과 미리보기 그림 |
| `icons/`, `manifest.json` | 홈 화면 아이콘 |
| `firestore.rules` | Firebase 보안 규칙 (콘솔에 붙여 넣는 용도) |
